# Wallet

## Connect
- Use the Connect Wallet button in the app.
- Verify network and address before proceeding.

## Balances & tokens
- View supported tokens and balances.
- Ensure sufficient SOL for fees (and collateral for Drift).

## Safety
- Approvals: grant minimal permissions.
- Spending caps: start low; raise gradually as confidence grows.
- Cold vs hot: prefer funded sub-accounts for testing.

## Operational checks
- Confirm RPC health and recent slot.
- Verify price feeds are updating in the UI.
- Keep a small SOL buffer for retries.

## Troubleshooting
- Insufficient funds → fund wallet and reduce notional.
- Signature declined → re-open wallet, re-approve.
- RPC rate limit → switch RPC or throttle via cooldown.
