# Logs

## Views
- Live stream: execution, simulation, errors.
- Filters: by severity, strategy, source.

## Common events
- sim.ok / sim.err: simulation outcome.
- send.ok / send.err: transaction submission.
- fill: expected vs executed size/price.

## Tips
- Filter to errors to diagnose rejections.
- Compare sim vs fill slippage.
- Export logs when reporting issues.
