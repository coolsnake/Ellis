# Glossary

<a id="adverse-selection"></a>
## Adverse Selection

Fills when price moves against you during execution.

<a id="bps"></a>
## Bps

Basis points; 1 bps = 0.01%.

<a id="cool‑down"></a>
## Cool‑down

Pause before next order to reduce churn.

<a id="hop"></a>
## Hop

One swap leg in a multi-pool route.

<a id="liquidity"></a>
## Liquidity

Depth available at or near the current price.

<a id="notional"></a>
## Notional

Gross USD value of a trade.

<a id="preset"></a>
## Preset

Named bundle of recommended parameter values.

<a id="route"></a>
## Route

A sequence of pools/exchanges for execution.

<a id="slippage"></a>
## Slippage

Difference between expected and executed price.

<a id="spread"></a>
## Spread

Difference between best bid and best ask.
